## Goal

Make typed positional arguments the default command contract in Rust and Lua. Replace the legacy compatibility contract with explicit raw text commands, migrate bundled structured commands and providers, and remove obsolete APIs without compatibility aliases.

## Implementation Summary

Continue the typed-command implementation in `.agents/makima-plans/129-directory-autocomplete-2-typed-arguments.md`. Preserve its shared parser, opaque completion candidates, generation/lifecycle guards, and shared `@`/typed-path grid. This change supersedes that plan's requirement to preserve `nargs` and command-wide providers.

Use `CommandArguments::Positional` or `Raw { required: bool }`, with equivalent static builtin declarations. Lua omitted `arguments` means an empty typed schema. Lua descriptor arrays declare positional arguments. `arguments = { raw = true, required = true }` declares required raw text; omitting `required` permits empty raw text. Remove Lua `nargs`, command-wide `completion`, `argument_completion`, and `completions`; reject these obsolete fields with useful errors rather than silently ignoring them. No compatibility variants or aliases.

Raw commands preserve the outer-trimmed remainder without command tokenization. Raw commands have no argument-completion provider. Keep `/btw`, `/rename`, Markdown substitution with arguments, and MCP's existing binding adapter raw. Migrate every other bundled command to typed schemas. No new argument-default feature, flags, subcommands, Markdown schema syntax, or MCP binding redesign.

## Implementation Plan

### 1. Core contracts and validation

- In `maki-commands/src/{arguments,spec,registry,dispatch,completion,completion_providers,lib}.rs`, replace `Legacy(ArgumentArity)` with `Raw { required: bool }`. Apply the same distinction to `StaticCommandArguments`. Make default/no-argument construction positional-empty.
- Remove raw whitespace-word counting and legacy arity constructors. If a min/max helper remains necessary for typed projections, derive it from the positional schema and name it as derived bounds rather than a raw declaration API. Raw optional has unbounded text and permits empty; raw required rejects an empty outer-trimmed remainder before behavior invocation. Quotes, repeated internal whitespace, newlines, and unmatched quotes remain literal in raw text.
- Preserve `CommandInvocation.arguments` for all commands and `parsed_arguments: Some(...)` for all positional commands, including empty schemas. Raw invocations have `None`. Preserve strict typed validation and exact integer bounds.
- Remove `Registration.completion` and legacy command-wide completion-session opening/query branches. Keep per-descriptor providers and reusable one-shot provider trait adaptation to incremental snapshots; a one-shot implementation is not a legacy command contract. Raw registrations reject argument providers. Keep policy/vector validation atomic.
- Retain candidate identity, generation issuance, snapshot revision, provenance, final-publication versus lifecycle termination, and callback-free validation before directory Advance. Do not simplify these fences while removing legacy branches.
- Update every constructor/projection across agent, Lua, UI, ACP, root print/SDK, and test fixtures. Remove compatibility-only fixtures or convert them to explicit raw behavior tests. Update UI exact-name matching to keep incomplete typed commands dispatchable and raw commands invocable without assuming whitespace arity.

### 2. Builtins and external producers

- In `maki-commands/src/spec.rs`, migrate no-argument builtins `/tasks`, `/compact`, `/new` (`/clear` alias), `/help`, `/queue`, `/mcp`, `/login`, `/yolo`, `/fast`, `/workflow`, `/exit`, and `/reload` to positional-empty. `/cd` remains optional Directory.
- Declare `/model` optional String `spec` and `/theme` optional String `name`. Add `completion: CompletionPolicy` and `provider: Option<CompletionKey>` to `StaticPositionalArgument`; model/theme descriptors use Replace with their Model/Theme keys. Convert policy into portable positional metadata and resolve each static descriptor's key against `StandardCompletions` when building the ordered `Registration.argument_completions` vector in `maki-agent/src/command.rs`. Supply a core empty one-shot provider for a keyed provider unavailable on a frontend (for example headless theme completion), keeping Replace policy/vector validation consistent while still allowing execution. Do not make command registration depend on a TUI provider being present. Delete `BuiltinDefinition.completion`. Keep callback objects outside comparable metadata and use no command-name schema switch. Update UI runtime wiring to supply the same provider implementations. `typed_builtin_selection_commands` must open both actual per-argument sessions, assert candidates and preview ownership, and dispatch decoded values.
- Builtin execution consumes decoded named values. Missing model/theme values open their pickers. Explicit empty strings produce a useful invalid-value error rather than becoming indistinguishable from omission. Preserve model provider/id handling, fuzzy unique resolution, theme matching, ambiguity errors, preview commit/cancel semantics, and target ownership.
- `/btw` uses required raw text and preserves attachments and literal source. Markdown producers with no arguments use positional-empty; producers accepting `$ARGUMENTS` or an argument hint use optional raw text and preserve substitution exactly.
- MCP stays optional raw at the command boundary and retains `parse_prompt_args` in `maki-agent/src/mcp/mod.rs`: it binds earlier positional words and the remaining text to the last prompt argument, then performs prompt-specific required checks. Do not replace it with the shared quote lexer or silently alter server-provided argument ordering. Keep prompt references, stale identity checks, and ACP advertisement intact.

### 3. Breaking Lua registration API

- Update `maki-lua/src/api/tool.rs` parsing to accept only omitted/empty positional arguments, dense descriptor arrays, or the explicit keyed raw table. Validate the raw table strictly: `raw` must be true, `required` must be boolean when present, and positional entries or unrelated fields are rejected. Reject mixed raw/positional forms atomically.
- Remove obsolete arity and command-wide callback fields from `api/util/command.rs::CommandEntry`, runtime registration projection, loader adapters, and callback lookup. Store the argument contract once rather than retaining arity plus optional schema. Use a staged-key guard that owns each newly allocated Lua registry key until successful registration transfers ownership; all parse, schema, provider and publication failures release staged keys on the Lua thread. Preserve immutable generation binding. Tests reject each obsolete field on omitted/empty, raw, and positional declarations, including false/non-nil values. After late descriptor failures and publication rejection, invoke the old handler and old descriptor provider/highlight/cancel hooks to prove atomic preservation and assert staged callback references are released.
- Keep descriptor completion omitted/default, false/disabled, and provider tables with replace/extend semantics. Do not add replacement aliases for removed command-wide APIs. Migrate test/plugin fixtures using them to per-argument providers or raw commands according to their actual behavior.
- Typed handler options: `opts.args` is original outer-trimmed source, `opts.fargs` is decoded tokens, and `opts.values` is the named table. Empty typed schemas get empty `fargs` and `values`. Raw handlers receive `opts.args` only for argument data: do not manufacture whitespace-split `fargs` or a misleading `values` table. Preserve unrelated invocation metadata.
- Add one core `CommandArguments::parse_invocation(&str)` helper returning `Result<Option<ParsedArguments>, ArgumentError>` (or the existing equivalent error type extended for required raw text). It implements positional parsing and raw presence validation. Registry dispatch calls it after target/winner validation; `RunCommand` reads the single stored `CommandEntry.arguments` contract and calls the same helper on outer-trimmed input. Registry `ExecuteCommand` uses its already-validated invocation rather than reparsing. Both routes call `set_lua_command_options_from_parsed`, which emits fargs/values only for Some(parsed). Keep Result replies and queued execution generation fences. `typed_and_raw_invocation_routes` must compare success and error semantics, including empty required raw input and absent raw fields.

### 4. Bundled Lua migrations

- No-argument commands `/automode`, `/build`, `/memory`, `/plan`, `/splash-fps`, and `/usage` omit `arguments` or use an empty array. Verify no accidental raw fallback.
- `plugins/splashes/init.lua`: optional String `splash`, dynamic replacement provider nested in the descriptor. Move all preview/highlight/accept/cancel hooks with it. Read `opts.values.splash`; omission opens the existing picker, explicit empty input errors. Preserve dynamic discovery and fuzzy matching rather than using a static Enum.
- `plugins/thinking/init.lua`: optional String `effort`, descriptor-local dynamic replacement provider. Read `opts.values.effort`; omission opens the selector, explicit empty input errors. Preserve host-dependent suggestions, named levels, numeric budgets, and persisted defaults. Do not constrain execution to the suggested list.
- `plugins/sessions/init.lua`: optional String `query`. The current `open()` ignores the advertised query; change the command adapter to pass the decoded query into picker initialization. Keep the keymap/autocmd no-argument path valid and preserve deadline-free command coroutine behavior. Quoted multiword queries initialize the picker filter and visible results. Raw `/rename` uses `arguments = { raw = true, required = true }` and consumes `opts.args` without quote decoding.
- Audit every direct bundled `register_command` declaration and handler usage of `args`/`fargs`. Do not change `@model` reference registration into a slash command.

### 5. Documentation and static extraction

- Extend `LuaPluginCommand` in `maki-docgen/src/lua_util.rs` with `arguments: CommandArguments`, reusing the core mode/schema representation instead of a parallel docgen model. Parse literal positional descriptor arrays and raw tables from direct inline registrations; omission becomes Positional(empty). Parse name/type/choices/optional/variadic needed for schema validation and hint generation. Completion callbacks remain opaque and are never evaluated; docgen does not validate provider binding through executable callbacks.
- Derive hints through the runtime core helper, preserving explicit hints. Use exactly `| Command | Description | Mode | Arguments | TUI-only |` for generated builtin and Lua command tables. Preserve the existing `Arguments` column for usage hints; add a separate `Mode` column containing `none` for positional-empty, `typed` for nonempty positional schemas, `raw (optional)` for optional raw, and `raw (required)` for required raw. Rendered-row tests assert both columns independently. Raw modes do not synthesize positional hints; retain explicit hints such as `<title>`. `typed_lua_usage_hint_parity` compares extracted contracts and hints with real runtime registrations. `generated_docs_contain_command_modes` asserts rendered rows for all four cases and absence of obsolete nargs/legacy API guidance.
- Preserve the direct inline-table grammar contract. Fail with a source location for malformed or unsupported dynamic schema expressions instead of silently omitting arguments. Add AST fixtures for optional/variadic arguments, empty/default schemas, raw required/optional, explicit hint precedence, and nonliteral schema rejection.
- Update canonical Lua registration docs in `api/tool.rs`, command-reference generation, and relevant API docs to describe typed defaults, raw text, options shape, and descriptor-only completion. Replace stale legacy/nargs claims and examples. Keep `/copy` a recording-only example.
- Regenerate existing references with `just gen-docs`; verify drift. Update the repository's latest typed-argument plan to point to the new contract and remove contradictory compatibility requirements. Do not introduce unrelated documentation or change reference completion APIs.

## Acceptance Criteria

- AC.1: Empty/omitted schemas reject extra input; positional schemas retain quote-aware validation; raw required/optional preserve literal inner text and enforce only presence. `command_argument_modes` covers empty, whitespace, quotes, multiline input, and required failures.
- AC.2: Lua accepts the new forms, rejects obsolete/mixed/malformed declarations, and failed registration leaves old handlers/providers usable. `lua_command_contract_registration` and `lua_raw_registration_is_atomic` verify this through a real host.
- AC.3: Both Lua invocation routes agree on typed and raw option tables and failures. `typed_and_raw_invocation_routes` asserts empty typed tables, optional/variadic values, absent raw fargs/values, and zero handler calls on invalid input.
- AC.4: All bundled structured commands use typed schemas; only intentional remainder consumers use raw. `bundled_command_argument_modes` asserts the published registry inventory, including all Rust builtins and bundled Lua commands.
- AC.5: Model/theme/splash/thinking execute decoded values and preserve dynamic suggestions, previews, cancellation, picker omission behavior, and numeric thinking budgets. `typed_builtin_selection_commands`, `typed_splash_completion_lifecycle`, and `typed_thinking_command` verify actual handlers/providers; explicit empty values fail without changing state.
- AC.6: `/sessions "multi word"` initializes visible filtering, no-argument keymap/autocmd still opens the picker, and raw rename preserves internal whitespace and quote characters. `typed_sessions_query_scenario` and `raw_rename_preserves_title` assert host/UI effects.
- AC.7: Markdown/MCP raw adapters preserve their intended binding, prompt references, and errors; argumentless Markdown commands are typed-empty. `raw_markdown_substitution` and `raw_mcp_prompt_binding` cover producer execution. Add `command_projection_modes` cases to ACP (`maki-acp/src/server.rs`), print (`src/print.rs`), and SDK (`src/sdk_mode.rs`) existing fake-host tests: publish empty typed, required raw, and optional raw fixtures; assert advertised hints/capability visibility, extra-input rejection for typed-empty, raw attachment/text preservation, and required-empty failure. Test model/theme registration with unavailable frontend completion providers to protect headless/ACP execution.
- AC.8: Completion removal/migration does not regress shared grid navigation, pending-row safety, snapshot provenance, queued handler generation fencing, or exactly-once preview cancellation. Run named existing regressions `queued_execute_command_rejects_retired_generation_before_worker_consumes_it`, `finished_custom_provider_is_cancelled_when_default_candidate_wins`, the completion snapshot replacement tests, shared grid parity tests, and `directory_descent_retains_rows_but_blocks_old_selection` after migrating their declarations.
- AC.9: Static docs show schema-derived hints and raw contracts, reject unsupported schemas, and match runtime projections. `lua_command_schema_extraction`, `typed_lua_usage_hint_parity`, `generated_docs_contain_command_modes`, and `just gen-docs-check` verify generated output.

## Risks, Blockers, and Required Decisions

- Approved: compatibility may break; remove nargs and command-wide completion rather than retaining aliases. Approved raw syntax is `arguments = { raw = true, required = true }`, with required defaulting false.
- Approved: `/sessions`' advertised query becomes functional. Keep open() callable from no-argument keymap/autocmd paths; do not interpret their event payloads as command options.
- Raw stays limited to `/btw`, `/rename`, argument-taking Markdown commands, and the current MCP binding adapter. MCP exposes metadata but its last-remainder binding differs from the typed lexer; changing that adapter is outside this scope.
- Explicit empty structured values differ from omitted values. Selection commands must reject empty values instead of accidentally opening pickers or applying defaults.
- Shared completion providers serve dynamic names and preview state. Do not replace them with static enums or terminate preview ownership at final publication.
- The current code has existing enum-default machinery. Preserve it as appropriate but do not expand default-value support as incidental migration work.
- No unresolved product decisions or accepted testing gaps remain. External Rust/Lua users would require migration, but compatibility is explicitly not a constraint for this project stage.
